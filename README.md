# Deniz OOP Learning System 🎓

Interactive OOP with Python reference — Istanbul Gelisim Universitesi · Fall 2025

## Made by YAHYA ALRAVNI
Under the supervision of "Prof. Dr. Deniz DAHMAN'S"

## What is this?
An interactive web-based system that helps students understand and remember 12 OOP concepts in Python — with live demos, Python code examples, and quick quizzes.

## Concepts Covered
- 🔒 Encapsulation
- 🧬 Inheritance  
- 🔀 Polymorphism
- 📐 Abstraction
- 🎨 Decorator (@property)
- 🔄 Override
- ⚡ super()
- 🏗️ Constructor (__init__)
- 📦 Class vs Instance Variables
- 🖨️ __str__
- 🔍 isinstance()
- 🔗 Multiple Inheritance
